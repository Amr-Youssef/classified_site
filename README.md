# سوق الإعلانات المبوبة

مشروع موقع إلكتروني بسيط للإعلانات المبوبة متعدد الفئات باستخدام PHP وMySQL. يدعم اللغة العربية والاتجاه من اليمين لليسار (RTL)، ويتيح للمستخدمين إنشاء حسابات، نشر الإعلانات، البحث والتصفية، التواصل، وإضافة الإعلانات إلى المفضلة.

## الإعداد

1. **إنشاء قاعدة البيانات:**
   - قم بإنشاء قاعدة بيانات جديدة باسم `classified_db` (أو أي اسم آخر). ثم نفّذ ملف `database.sql` الموجود في هذا المجلد لإنشاء الجداول الأساسية.
   - يمكنك استخدام phpMyAdmin أو سطر الأوامر:

     ```bash
     mysql -u root -p classified_db < database.sql
     ```

2. **تعديل إعدادات الاتصال:**
   - قم بتعديل ملف `config.php` لتحديد اسم المضيف وبيانات الدخول الخاصة بقاعدة البيانات (`$db_host`, `$db_name`, `$db_user`, `$db_pass`).

3. **إضافة البيانات المبدئية (اختياري):**
   - يمكنك إدخال بعض الأقسام في جدول `categories` لبدء العمل. مثال:

     ```sql
   INSERT INTO categories (id, parent_id, name) VALUES
   (1, NULL, 'سيارات'),
   (2, 1, 'قطع غيار سيارات'),
   (3, 1, 'شاحنات'),
   (4, 1, 'أرقام مميزة'),
   (5, NULL, 'عقارات'),
   (6, 5, 'بيوت / فلل'),
   (7, 5, 'أراضي'),
   (8, 5, 'شقق'),
   (9, NULL, 'أجهزة'),
   (10, NULL, 'مواشي وحيوانات'),
   (11, NULL, 'أثاث'),
   (12, NULL, 'خدمات'),
   (13, NULL, 'وظائف'),
   (14, NULL, 'أقسام أخرى');
     ```

4. **تشغيل الموقع:**
   - ضع مجلد `classified_site` في مسار سيرفر PHP (مثلاً في مجلد `htdocs` في XAMPP أو في `public_html`).
   - افتح المتصفح وانتقل إلى `http://localhost/classified_site/index.php` لمشاهدة الموقع.

## الميزات الرئيسية

- **واجهة مستخدم عربية RTL:** يتم دعم اللغة العربية بشكل كامل مع الاتجاه من اليمين إلى اليسار.
- **تسجيل الدخول وإنشاء حساب:** يمكن للمستخدمين إنشاء حسابات وتسجيل الدخول وإدارة حساباتهم.
- **نشر الإعلانات:** يمكن للمستخدمين إضافة إعلانات جديدة مع إمكانية رفع عدة صور واختيار القسم والحالة والسعر والموقع.
- **تصفح الإعلانات:** يمكن للمستخدمين تصفح الإعلانات حسب الأقسام، البحث بالكلمات المفتاحية، وتصفية النتائج حسب السعر والحالة.
- **الرسائل والمفضلة:** يمكن للمستخدمين مراسلة أصحاب الإعلانات مباشرةً وإضافة الإعلانات إلى قائمة المفضلة.
- **صفحة المستخدم:** تحتوي على معلومات الحساب وقائمة الإعلانات المفضلة والرسائل الواردة.

### الإعلانات المميزة (مدفوعة)
- تفعيل الترقية من صفحة الإعلان (مالك الإعلان فقط) مع تسعير مرن.
- موفّر دفع: mock (تجارب) أو Moyasar (واجهة حقيقية).
- عند الدفع الناجح، يتم تمديد premium_until تلقائياً.
- لوحة الإدارة: إطفاء/تمديد التمييز وفلترة سجل promotions.

## ملاحظات

- تم تصميم الموقع ليكون مرناً وقابل للتطوير؛ يمكنك إضافة المزيد من الميزات مثل الدفع للإعلانات المميزة أو نظام الإشعارات بسهولة.

## النشر والإعداد للإنتاج

1) المتطلبات
- PHP 7.4+ مع الامتدادات: pdo_mysql, mbstring, openssl, zip
- MySQL/MariaDB
- Composer (لتثبيت PHPMailer)
- خادم ويب (Apache/Nginx)

2) إعداد البيئة
- انسخ `.env.example` إلى `.env` وحدّد القيم (قاعدة البيانات، البريد، مزود الرسائل، SITE_BASE_URL، APP_ENV=production).

3) تثبيت الاعتمادات
```
composer install --no-dev --optimize-autoloader
```

4) قاعدة البيانات
- نفّذ `database.sql` مرة واحدة لإنشاء الجداول.
- يمكن تشغيل `php scripts/migrate_email_verification.php` لضمان جداول التفعيل.

5) البريد والرسائل
- البريد: اضبط EMAIL_PROVIDER=smtp مع إعدادات SMTP، أو sendgrid، أو mock للتجارب.
- الرسائل النصية: SMS_PROVIDER=mock للتجارب، أو Twilio/Unifonic للإنتاج.

6) الأمان
- عند الإنتاج: `APP_ENV=production` لتعطيل عرض الأخطاء وتفعيل التسجيل في `storage/php-errors.log`.
- استخدم HTTPS واضبط الكوكيز بشكل آمن.

7) فحص سريع
- افتح `/index.php` وتحقق من عدم وجود أخطاء.
- جرّب إرسال بريد اختبار: `php scripts/email_smoke_test.php?to=you@example.com`

8) الدفع والإعلانات المميزة
- عدّل `.env` (أو متغيرات البيئة):
   - mock: `PAYMENT_PROVIDER=mock`
   - Moyasar: `PAYMENT_PROVIDER=moyasar`, ضع `MOYASAR_PUBLISHABLE_KEY`, `MOYASAR_SECRET_KEY`, `MOYASAR_CURRENCY`.
- شغّل ترحيل الترقية:
   - `php scripts/migrate_promotions.php`
- اختبر كمالك إعلان: اختر مدة ثم ادفع، تأكد من ظهور التمييز. افتح لوحة الإدارة لإدارة التمييز.
